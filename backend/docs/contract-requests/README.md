# Запити на зміни контрактів між модулями

Контракти лежать у `src/common/contracts/<module>.ts` і належать агенту відповідного модуля
(див. `src/common/contracts/README.md`). Якщо вашому модулю потрібен новий метод сервісу, нове поле
у DTO результату або нова подія outbox від іншого модуля:

1. Створіть `docs/contract-requests/<споживач>-to-<власник>-<n>.md`, наприклад
   `notifications-to-receipts-1.md`, з полями:
   - Що потрібно: сигнатура методу або назва події і форма payload (TypeScript-фрагмент).
   - Для чого: сценарій з BRIEF (розділ, ендпоїнт або задача воркера).
   - Коли: блокує роботу зараз чи може почекати до інтеграції.
2. До відповіді кодуйте проти власного локального інтерфейсу в `domain/` або `services/` вашого модуля
   і адаптера-заглушки; після погодження замініть його імпортом із контракту.
3. Власник контракту додає зміну у свій файл, за потреби реалізує її та закриває запит рядком
   `Статус: виконано <дата>` або `Статус: відхилено, причина`.

Події outbox іменуються `module.event` або `module.aggregate.event` (малі літери, крапки), payload - лише
JSON-сумісні значення з ідентифікаторами та фактами, потрібними споживачу, без цілих сутностей.

English summary: cross-module interface and event changes are requested here; the owning module's agent
updates `src/common/contracts/<module>.ts` and closes the request.
