# Залежності модуля notifications

| Пакет                 | Версія | Навіщо                                                                  | Альтернатива без пакета (поточна реалізація)                                    |
| --------------------- | ------ | ----------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| `google-auth-library` | `^10`  | OAuth2-токени сервісного акаунта Google для FCM HTTP v1 (необов'язково) | `ServiceAccountTokenProvider`: JWT RS256 на `node:crypto` + `fetch`, кеш токена |
| `firebase-admin`      | `^13`  | повний SDK FCM (необов'язково)                                          | `FcmPushAdapter`: прямий виклик `POST /v1/projects/:id/messages:send`           |

Встановлювати не потрібно: модуль працює на наявних залежностях. Запит фіксує варіант на випадок,
якщо команда віддасть перевагу офіційним SDK (ротація ключів, нові поля FCM).

Статус: відхилено 2026-11-01 (integration): пакети не встановлюємо - адаптер FCM на `node:crypto` і `fetch` покритий тестами; повернутися, якщо команда обере офіційні SDK.

English summary: optional Google SDKs; the module already works without them.
